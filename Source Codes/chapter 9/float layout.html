Toay, one cannot imagine the world without the internet, the websites, the apps and devices etc. Tim Berners Lee developed HTML that uses tags to design web documents. He also developed a web browser that can interpret and render the HTML documents.

Lee also proposed HTTP (Hypertext Transfer Protocol) for the client to request for a certain HTML document and the server to transmit the same. HTTP protocol is the foundation of data communication for the World Wide Web.
